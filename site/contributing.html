Report, discuss, then ship with us.

Where each request goes

You have Go to
A bug in a skill Bug issue
A change to an existing skill, or a new skill that clears the bar Idea or feedback issue
A question, or "how do I…?" Discussions: Q&A

If you are a collaborator

One problem per issue. Repro first. Keep the manifests in sync.

  1. 01 · Issue Open an issue describing the observed failure: what you ran, what happened, what you expected. Short.
  2. 02 · Branch Branch from main, change the skill, and keep README.md, the bucket README, plugin.json, ask-yami, and UPSTREAM.md in sync.
  3. 03 · Check Run skill-eval on every skill you changed, and npm run check-plugin-version.
  4. 04 · Changeset Add a changeset for any user-visible change, then open the PR. No em-dashes in prose.
