The set

Skills

You type the ship doors and the setup commands. The model can also reach the procedures when the task fits. A user-invoked skill never calls another user-invoked skill.

Engineering · you type

  • ask-yamiWhich skill or flow fits this moment.
  • setup-z-yami-coding-skillsTracker, labels, branching, surfaces. Once per repo.
  • grill-with-docsInterview that keeps the glossary and ADRs current.
  • wayfinderA foggy effort, charted as decision tickets.
  • to-specOne spec, with its base recorded.
  • to-ticketsTracer bullets, blockers, and bases.
  • ship-ticketOne ticket. You approve the land.
  • ship-specOne spec. Session lands tickets. You approve the spec.
  • ship-releaseThe whole release. You approve the PR into main.
  • implement-specEvery ticket of one spec, one pull request.
  • landMerge into the recorded base and restack.
  • sync-skillsUpdate this package, then apply its file migrations.
  • releaseStart, finish, or hotfix one phase.
  • design-taste-frontendLanding pages and product UI with dealt layout, motion, and a finish gate.

Engineering · the model can reach

  • branch-lineageBases, worktrees, landing, restack.
  • ticket-flowThe procedure behind ship-ticket.
  • spec-flowThe procedure behind ship-spec. Steers and lands tickets.
  • release-flowThe procedure behind ship-release.
  • code-reviewStandards and spec, plus security and deep on request.
  • security-reviewOnly findings you can exploit.
  • tddRed, green, and a test for risky logic.
  • diagnosing-bugsA tight feedback loop before a theory.
  • herdrTUI panes, when HERDR_ENV is set.
  • herdr-coreDesktop terminals, with hc.
  • herdr-appThe Desktop window: spaces, tabs, panes.
  • surface-mapMonorepo surfaces and the contracts between them.

Productivity
