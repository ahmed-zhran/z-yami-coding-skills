The ship door you type owns that level's land gate. `/ship-ticket` waits only on the ticket pull request. `/ship-spec` lands tickets and waits only on the spec pull request. `/ship-release` lands tickets and specs and waits only on the release pull request into `main`. The shipping session also steers every ticket pane it opened (shell approvals and child questions; mid-build asks only for a doc break or unsettled breaking change).
