A spec ticket lands into `spec/<issue>`, and that spec lands into `release/<N>`. A bug ticket lands into the open release, a hotfix cut from the production tag, or `main` when no release is open. `/ship-release` publishes every spec the release needs. `/sync-skills` applies the migration records that shipped after the installed version, including the one that updates a consumer `docs/agents/branching.md` to these levels. The package site is [yami-coding](https://ahmed-zhran.github.io/yami-coding).
