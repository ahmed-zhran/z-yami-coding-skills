Product releases write a blocking human-testing checklist at `docs/releases/<N>/human-testing.md` (user stories by surface, checkboxes, notes, Sign-off). Sign-off Approved is required before the release tag; the release PR is not a substitute. After the tag, pending-release includes a human-testing feedback box that turns fails and notes into next-release work. New files must use a named home (`docs/releases/<N>/`, `docs/agents/`, …), not an ad-hoc path at a folder root.
